## Ограничения Для Generated System

- Existing local skills с authoritative triggers должны быть routed или wrapped, а не overwritten.
- Generated skills не должны дублировать existing skill names/paths.
- Existing references, которые используют local skills, должны остаться reachable.
- Unresolved authority conflicts блокируют skills generation.
